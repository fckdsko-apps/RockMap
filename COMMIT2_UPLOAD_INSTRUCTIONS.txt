UPLOAD METHOD
1. Extract this ZIP locally.
2. In the RockMap GitHub repository, upload/replace the files using the exact paths in this package.
3. Do not add or change anything under .github. This package intentionally contains no .github directory.
4. Commit all packaged changes together with the exact commit name above.
5. Run the existing Build RockMap APK workflow as usual.
6. Do not uninstall the existing RockMap app before installing the resulting APK; install it as an update so existing offline/user data remains available.

WHAT CHANGES
- Main map Minerals button becomes Research; the existing mineral search remains available inside Research.
- Adds a local queryable Colorado geology database installed explicitly from Research.
- First geology install/refresh downloads Colorado-only USGS SGMC polygons from the public ArcGIS FeatureServer, validates the state/count/required geometry, then atomically activates the local SQLite snapshot.
- Geology queries are offline after installation.
- Search supports unit/label/lithology/age terms, installed-data suggestions, optional filters, and visible-map scope.
- Spatial queries support visible map bounds, saved prospecting polygons, and coordinate/radius searches.
- Research results map as a temporary geology overlay below land/claim/saved-location safety layers.
- Research can cross-reference the existing mineral evidence and historic mine/workings systems without duplicating those datasets.
- Field Records gain Research geology here.
- Saved prospecting areas gain Analyze geology & evidence using the actual saved polygon.
- Field > Export data gains Research result export as GeoJSON or CSV.
- The last Research result is stored locally rather than passed through Android Intent extras, avoiding Binder-size crashes on polygon results.
- Downloadable geology and reproducible Research-result files are excluded from Android cloud backup/device transfer; user-created Field/Trip/Saved data remains backup-eligible.
- Privacy policy now accurately distinguishes release-managed pack SHA/size verification from the live USGS geology snapshot validation.
