RockMap offline glyph resources

Alpha 3 uses MapLibre glyph PBF resources derived from Noto Sans Regular.
The source patch does not include a TTF/OTF font file or glyph PBF binaries.
During the Android build, scripts/prepare_offline_glyphs.py fetches a small,
pinned set of glyph PBF ranges from the Protomaps basemaps-assets repository,
verifies the immutable Git blob identities, rewrites only the font-stack label
to RockMapSans, and places the results in Gradle's generated-assets directory.
