RockMap offline text resources

Alpha 3.1 prepares two local MapLibre Native text paths from Noto Sans Regular:
SDF glyph PBF ranges and a local TTF font face. The source patch itself does not
include a TTF/OTF font file or glyph PBF binaries. During the Android build,
scripts/prepare_offline_glyphs.py fetches pinned upstream resources from immutable
commits, verifies their Git blob identities, aliases the PBF stack to RockMapSans,
and writes the PBF and TTF outputs only to Gradle's generated-assets directory.
